# Анализ шансов поступления в вузы

## 📌 Описание проекта

Проект разработан для оценки вероятности поступления в целевые вузы на основе данных приемной кампании 2026 года. 

Система выполняет:
- Парсинг конкурсных списков абитуриентов с сайтов 8 вузов.
- Фильтрацию кандидатов по пороговому баллу.
- Сбор и обработку данных о согласиях на зачисление из 24 внешних вузов.
- Очистку данных от "шума" (исключение абитуриентов, подавших согласие в другие вузы).
- Расчет итоговых шансов поступления с учетом актуальных согласий и прогнозной модели.

> ⚠️ **Важное примечание:** Проект выполнялся в период приемной кампании 2026 года. В настоящее время таблицы абитуриентов удалены с сайтов вузов, поэтому код не может быть запущен повторно. Однако **вся логика обработки, алгоритмы фильтрации и итоговые расчеты** сохранены для ознакомления.

## 🔍 Алгоритм работы

### Этап 1: Парсинг конкурсных списков

- Загрузка каталогов конкурсов по каждому вузу.
- Фильтрация бюджетных программ с общим конкурсом (план > 0).
- Парсинг списков абитуриентов с актуальными данными о согласиях.

**Пример вывода:**
Загрузка каталога конкурсов МИРЭА (бак/спец, очная, Москва)...
Программ в каталоге: 97.
Программ с бюджетным общим конкурсом (план > 0): 84.
Целевых программ: 13 (из 13 строк ТЗ).
[1/84] Математическое моделирование и вычислительная [Очная]
мест общ.конкурса=31, порог=269, строк=1501


### Этап 2: Сбор согласий из внешних вузов

- Сбор данных о согласиях на зачисление из 24 вузов-конкурентов.
- Каждый вуз проверяется на наличие согласий абитуриентов из целевого списка.

**Пример вывода:**
Сбор согласий внешних вузов (24 в реестре)...
ВШЭ: 3455 согласий (36 сек).
МАДИ: 1203 согласий (14 сек).
МИЭТ: 1192 согласий (1 сек).
РХТУ им. Менделеева: 1521 согласий (3 сек).


### Этап 3: Фильтрация и очистка данных

- Проверка индивидуальных номеров абитуриентов по всем вузам.
- Исключение кандидатов, подавших согласие в другой вуз.
- Расчет реального количества мест с учетом "отказников".

**Пример обработки:**
БЛОК 1: МИРЭА
Аппаратное программирование встраиваемых систем (09.03.01)
Мест общего конкурса: 17 | Порог отбора: 277 | Всего строк: 472
Основной ВП (да): 17 | Проходной ВП (да): 2 | Сумма (да): 19
Проходной балл вуза сейчас: 263 | Проходной, если бы согласились все: 288


### Этап 4: Расчет шансов поступления

- Для каждой целевой программы рассчитывается:
  - Текущий проходной балл (среди подавших согласие).
  - Прогнозный проходной балл (если согласятся все из списка).
  - Вероятность поступления с учетом конкретных баллов абитуриента.
- Результаты сохраняются в Excel-файлы с разбивкой по вузам и программам.

**Пример финального вывода:**
ШАНСЫ НА ПОСТУПЛЕНИЕ (предсказательная модель)
Наши баллы ВИ: математика 90, русский 91, физика 86, информатика 78.
Итоговый балл: 277 (с физикой) / 259 (с информатикой)

МИРЭА
Программа | Бюджетные места | Наши баллы | Шанс | Проходной (все)
Аппаратное программирование | 17 | 277 | 99% | 288
Инфраструктура ИТ | 33 | 269 | 99% | 285

## 🛠️ Используемые технологии

Проект написан на **Python 3.9+** и использует следующие библиотеки:

### Основные

- **pandas** — обработка и анализ табличных данных
- **requests, urllib3** — HTTP-запросы для парсинга веб-страниц
- **BeautifulSoup4 (bs4)** — парсинг HTML-страниц вузов
- **openpyxl** — работа с Excel-файлами (чтение/запись)

### Вспомогательные

- **IPython** — вывод таблиц и форматирование в Jupyter (`display`, `Markdown`)
- **pickle** — сохранение промежуточных данных (кэширование)
- **concurrent.futures, threading** — многопоточный парсинг для ускорения сбора данных
- **pdfplumber** — извлечение данных из PDF-файлов (используется опционально)

### Стандартные библиотеки Python

`os`, `sys`, `re`, `json`, `time`, `hashlib`, `base64`, `quopri`, `zipfile`, `subprocess`, `glob`, `io`, `urllib.parse`, `collections`, `site`, `importlib`

## 🧩 Архитектура кода

Блокнот построен по принципу **автономных блоков**. Каждый блок:

- Содержит все необходимые импорты внутри себя.
- Может быть выполнен независимо от других.
- Отвечает за работу с конкретным вузом или этапом обработки.

Это позволяет:

- Обновлять данные только по одному вузу без перезапуска всего блокнота.
- Быстро тестировать изменения для конкретной программы.
- Изолировать ошибки — сбой в одном блоке не влияет на другие.

## 📊 Результаты

Итоговые таблицы сохранены в папке `data/processed/`:

- **`финальная_статистика.xlsx`** — финальные таблицы по всем целевым программам. Каждый лист назван по вузу, программы расположены друг под другом. Содержит номера в очереди, коды абитуриентов, сумму баллов, статус согласия, приоритет, отметки об основном и проходном ВП.

- **`шансы_поступления.xlsx`** — прогнозные шансы поступления с учетом конкретных баллов абитуриента. Содержит название программы, бюджетные места, минимальный проходной балл, наши баллы, шансы поступления (текущие и прогнозные), проходной балл, если согласятся все.
